# مراجعة مساحة الاكتشاف 3.0

الفرع مستقل عن main. لا ينشر هذا التغيير الموقع الأساسي.

## قبل وبعد

| قبل | بعد |
|---|---|
| عنوان عام وتعليمات نظرية | عنوان يوضح التحول الرقمي وتجربة اختيار وتفسير |
| قائمة محاور بلا هدف | هدف واضح لكل محور |
| مختبر داخل نافذة طويلة ونتيجة مؤقتة | شاشة مستقلة وتقدم محفوظ وروابط للمحاور |
| تفاعل واحد متكرر | ترتيب خطوات ومقارنة دليلين ومعلومة ناقصة |
| نتيجة عددية فقط | مفاهيم للمراجعة وتطبيق مرتبط بالمحور |
| شعار منفرد للمشاركة | غلاف 1200×630 بسؤال وتفسير والشعار الأصلي |

## التحقق الفعلي

اجتازت تدفقات التجربة القصيرة والإجابة الخاطئة والتلميح والصحيحة والتأمل والملاحظات والاستئناف والنتيجة والمختبر المحفوظ والأنشطة الثلاثة والرجوع، في إطارات متصفح بعرض 360 و390 و768 و1440 بكسل.

axe-core: صفر مخالفات مرصودة في 16 حالة شاشة/مقاس: الرئيسية، السؤال، النتيجة، المختبر. لا يثبت الفحص الآلي وحده توافق WCAG الكامل.

لم يتغير أي معرّف من السيناريوهات الستة عشر أو أي مفتاح من الإجابات الثماني والأربعين أو سجل المراجع. تغيرت ستة بدائل خاطئة لتقليل إشارات التخمين. المفتاح discovery-lab-v2 بقي كما هو؛ اختُبر حفظ الملاحظات والاستئناف بعد إعادة التحميل. بيانات المختبر تستخدم مفتاحًا منفصلًا.

فشل تشغيل Chromium المستقل بقيود socket في البيئة؛ لذلك لم يصدر تقرير Lighthouse. نُفذت الاختبارات داخل متصفح المعاينة عبر review/qa.html. لم تُدّعَ نتيجة أداء.

نُقلت واجهة قابلة للتحرير إلى Figma، ثم وصل الاتصال إلى حد أدوات خطة Starter. لم يُنفذ فحص Stark ولا اكتمال مكونات تصميم Figma.

## إعادة التشغيل

npm ci
npm run dev

افتح /review/preview.html للمقارنة، و/review/qa.html للاختبارات. يتطلب فحص axe نسخ node_modules/axe-core/axe.min.js إلى review/axe.min.js (ملف غير متتبع). صفحة المقارنة تتيح المقاسات الأربعة.

## حدود

الاختبار على مقاسات إطارات متصفح، وليس أجهزة iPhone فعلية. الكتابة الحرة للمراجعة الذاتية ولا تُقيّم آليًا. لم يُنفذ اختبار مستخدمين. صورة المشاركة وبياناتها جاهزة في الفرع؛ تفعيلها على الرابط الأساسي يتم عند دمج ونشر الفرع.

اختبار لوحة المفاتيح اليدوي: اختيار التجربة القصيرة بـ Space والتحقق بـ Enter نجح.
